# HostelHub – Android Application

## About the Project

HostelHub is an Android application designed to support hostel-related management activities through a mobile interface.

## Features

- Student registration and personal information
- Attendance management
- Complaint management
- Event details
- Student gate pass management

## Technologies Used

- **Frontend:** Android Studio, Java, XML
- **Backend:** PHP
- **Database:** MySQL / MariaDB
- **API Testing:** Postman

## Project Structure

- `app/` – Android application source code and resources
- `gradle/` – Gradle wrapper configuration
- `build.gradle.kts` – Project build configuration
- `settings.gradle.kts` – Gradle project settings

## Setup Instructions

1. Clone or download this repository.
2. Open the project in Android Studio.
3. Allow Gradle synchronization to finish.
4. Configure the PHP backend and database separately.
5. Update the API URL in the Android app to match the backend server.
6. Run the app on an emulator or Android device.

## Note

The PHP backend and database must be configured separately for features that depend on the server.
